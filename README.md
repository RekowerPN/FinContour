# 🚀 ФинКонтур 2026 — Интеллектуальный анализ бюджетных потоков

**ФинКонтур** — интерактивное веб-приложение (SPA) для региональных министерств финансов. Система превращает бюджетные данные в наглядную картину финансовых потоков, автоматически выявляет нарушения и предоставляет инструменты сценарного анализа.

🔗 **Живая демонстрация (GitHub Pages):** [https://твой-юзернейм.github.io/финконтур](https://твой-юзернейм.github.io)

## 📂 Состав репозитория

| Файл | Назначение |
|------|------------|
| `ФинКонтур_levels_1.html` | Основное приложение: дашборд, таблицы, KPI, экспорт, голосовой ввод |
| `byte-sized-arcade_3.html` | Лендинг-презентация проекта, архитектура, дорожная карта |

Оба файла полностью самодостаточны, не требуют сервера или сборки.

## ⚡ Ключевые возможности

- **3 уровня доступа** (Начинающий / Продвинутый / Эксперт) с сохранением в браузере  
- **4 источника данных**: РЧБ (роспись и лимиты), Соглашения, БУАУ (касса), Контроль  
- **Автоматический аудит**: превышение лимитов, отрицательные остатки, нарушение дисциплины  
- **KPI в реальном времени**: лимиты, подтверждённые обязательства, касса, количество нарушений  
- **Голосовой ввод** через Web Speech API (поиск по таблицам микрофоном)  
- **Экспорт в Excel и PDF** – выгрузка таблиц, встроенные диаграммы, сводные отчёты с аналитической запиской  
- **Карта финансовых потоков** (Canvas) – интерактивный граф от источников до КВР, зумирование, выделение узлов, экспорт выбранных линий в PDF  
- **Сценарный анализ (What-If)** – изменение лимитов/обязательств/кассы с мгновенным пересчётом рисков и сохранением сценариев  
- **Динамика за год** – столбчатые и круговые диаграммы, сравнение с предыдущими периодами  
- **Тёмный минималистичный интерфейс**, пагинация, поиск, фильтры КЦСР / КВР / бюджет  

## 🛠️ Технологический стек

| Категория | Инструменты |
|-----------|-------------|
| Языки | HTML5, CSS3 (переменные, Grid, Flexbox), JavaScript (ES6+) |
| Архитектура | SPA (Single Page Application), весь код в одном HTML |
| Визуализация | Canvas API, SVG, встроенные диаграммы (столбчатые, круговые) |
| Экспорт | SheetJS (xlsx), jsPDF + pdfmake, JSZip (встраивание диаграмм в Excel) |
| Голосовое управление | Web Speech API (SpeechRecognition) |
| Хранение | LocalStorage (уровень доступа, сохранённые сценарии) |
| Шрифты | Google Fonts (IBM Plex Mono, Playfair Display, Source Sans 3, Unbounded, JetBrains Mono, Syne) |

## 🧩 Уровни доступа

| Уровень | Название | Возможности |
|---------|----------|-------------|
| 🟢 1 | Начинающий | Просмотр РЧБ, формирование отчёта, экспорт Excel / PDF |
| 🟡 2 | Продвинутый | Все источники, фильтры КЦСР/КВР, поиск, контроль нарушений, голосовой ввод |
| 🔴 3 | Эксперт | Карта потоков, сценарный анализ, динамика за год, все визуализации |

Изменение уровня – клик по индикатору в шапке, выбор сохраняется локально.

## 🗺️ Карта потоков (Уровень 3)

- Граф на HTML5 Canvas: источники финансирования → бюджеты → программы (КЦСР) → типы закупок (КВР)  
- Фильтр по источникам: федеральные, региональные, муниципальные  
- Переключение отображения: лимиты / касса / оба значения  
- Интерактивные подсказки с суммами и процентами, выделение связанных узлов  
- Экспорт выделенных маршрутов в PDF с аналитической запиской и предложениями по рискам  

## ⚙️ Сценарный анализ (Уровень 3)

- Ползунки для изменения лимитов/обязательств/кассы в процентах  
- Применение изменений к группам КВР, КЦСР или всем записям  
- Автоматический пересчёт итоговых KPI и таблиц по КВР  
- Выявление новых рисков (превышения, низкое освоение, концентрация)  
- Сохранение и загрузка сценариев в LocalStorage  

## 📊 Вкладки данных

1. **РЧБ** – роспись лимитов ПБС, подтверждённые обязательства, остатки, выбытия  
2. **Соглашения** – планирование выплат по заключённым соглашениям  
3. **БУАУ / Касса** – данные о кассовом исполнении бюджета  
4. **Контроль** – автоматически выявленные нарушения с подсветкой  

## 🧭 Дорожная карта

Проект развивается поэтапно:

- **Этап 1 (1–3 мес.)** – API-шлюз к СУБД Минфина, Web Workers, IndexedDB  
- **Этап 2 (4–6 мес.)** – Process Mining, цифровой двойник бюджета, продвинутая визуализация потоков  
- **Этап 3 (7–12 мес.)** – ИИ-аудит (NLP, графовые нейросети), криптографическая защита выгрузок (Merkle Trees)
