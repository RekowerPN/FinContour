О проекте

Что такое
ФинКонтур?

ФинКонтур — это интерактивное аналитическое веб-приложение, которое превращает сырые бюджетные данные в понятную картину финансовых потоков.

Система отвечает на ключевые вопросы: где деньги, куда они идут и где есть нарушения.

Проект имитирует реальную систему финансового контроля уровня регионального Минфина — с полным набором инструментов аудита, аналитики и визуализации.

Веб-инструмент для выявления финансовых рисков без установки дополнительного ПО. Всё в одном HTML-файле.

финконтур / index.html
// Инициализация системы
const fincontour = {
  mode: "regional_minfin",
  tabs: ["РЧБ", "Соглашения",
       "БУАУ", "Контроль"],
  levels: [1, 2, 3],
  export: ["xlsx", "pdf"],
  voice_input: true,
  spa: true
}
 
// ✓ Система готова к работе

Ключевые возможности

Что умеет
система

📊
Аналитика в реальном времени

Агрегирование данных по лимитам, обязательствам и кассовому исполнению. Автоматический пересчёт KPI и динамика за год.

🧠
Умный контроль

Выявление превышений лимитов, проверка бюджетной дисциплины и автоматическая подсветка аномалий в данных.

🎤
Голосовой ввод

Поиск по таблицам с помощью голоса — просто скажи название КЦСР, КВР или получателя. Работает без интернета.

🗺
Визуализация потоков

Карта финансовых потоков и сценарный анализ для глубокого понимания бюджета. Доступно на уровне Эксперт.

📤
Экспорт отчётов

Выгрузка данных в Excel и PDF одним нажатием. Отчёт формируется автоматически на основе текущих фильтров.

🖥
Минималистичный UI

Тёмный интерфейс с акцентом на читаемость. Sticky-панель, KPI-блоки, интерактивные таблицы с пагинацией.

Как использовать

Инструкция
за 5 шагов

01
Выбери период

Укажи месяц или год для формирования отчёта. Система поддерживает произвольные диапазоны дат.

02
Выбери источники

Подключи нужные источники: РЧБ, Соглашения, БУАУ, ГЗ. Комбинируй для сквозного анализа.

03
Примени фильтры

Настрой КЦСР, КВР, получателей или используй голосовой поиск для быстрого нахождения данных.

04
Сформируй отчёт

Нажми «Сформировать отчёт» — система автоматически пересчитает все KPI и обновит таблицы.

05
Анализируй и экспортируй

Изучай данные, ищи аномалии, выгружай в Excel или PDF одним кликом прямо из интерфейса.

Философия проекта

Принципы,
которыми живём

01
Прозрачность прежде всего
Бюджет — это деньги граждан. Каждый рубль должен быть видим, объясним и проверяем. Никаких скрытых потоков.
02
Один файл — полная система
Никаких серверов, баз данных или сложной инфраструктуры. Весь функционал живёт в одном HTML-файле — открыл и работаешь.
03
Данные честнее слов
Любое утверждение должно подкрепляться числами. Система показывает факты, а не интерпретации — решение за человеком.
04
Скорость — это уважение
Аналитик не должен ждать. Фильтры, пересчёт KPI, экспорт — всё мгновенно. Производительность заложена в архитектуре с нуля.
05
Ошибка — это сигнал
Превышение лимита — не баг системы, а факт реальности. Задача ФинКонтура — не скрыть, а выделить, объяснить и направить к решению.
06
Сложность — враг доверия
Если аналитик не понимает интерфейс за 5 минут — мы проиграли. Каждое решение по UX проходит проверку: «Это добавляет ясность или шум?»
